# R1‑7A 晚间实机联调 · 2026-11-17

## 固定试拍流程

1. 检查机械臂串口、C60E 占用和收拢位读数。确认这一镜头经过的桌沿、臂体、支架和线束留有净空。
2. 独立运镜统一从 **2026-11-17 21:06 展开位**启动。程序先抬开 J4，再抬 J2。对照 `field/standby-reference.txt` 核对七轴，带电稳定满 5 秒。
3. 稳定后开启录像，C60E 写入首帧后执行镜头。组合镜头按顺序连续执行，各关键机位留足取景时间。
4. 结束时带电慢收。先下放 J2，再收 J4 和 J7，到达收拢位后释力，复读确认七轴均为 `mode 0`。
5. 保存原始录像、关节反馈、起点校验与停机读数。用画面检查主体和标签是否完整、各机位构图是否有差别，再检查动作是否有明显停顿。

O6N 的 `captures/` 按场次保留 `camera.mkv`、`arm.log`、`report.json` 和 `session.json`。实拍入口的 `--reference` 参数填写该场次的收拢位检查记录，展开起点由 `field/standby-reference.txt` 统一提供。检查连接和停机姿态可用 `./field/check.sh check` 与 `./field/check.sh snapshot`。

已验证的带录像入口包括 `pan-powered-record`（左右扫镜）、`pan-tilt-powered-record`（扫镜与抬镜）及 `wrist-tabletop-record`（桌面下俯取景）。桌面取景会自动慢收。扫镜和抬镜结束后带电保持，向会话进程发送 `SIGUSR2` 请求慢收。

## 模型标定资料准备

```bash
python3 field/calibration.py inspect captures/实际快照目录/arm.log
python3 field/calibration.py template captures/实际快照目录/arm.log --out observations.json
```

模板把当前七轴原始角度放在每轴参考点 A，随后填写该姿态独立测得的 `model_deg`，再填第二姿态 B 的电机读数和模型角度。工具会给第三姿态 C 留出复核项。若本轮只有两点，先删除未测的 C 项，报告会标记独立复核尚缺。`whole_turn_equivalent_deg` 只作角度分支参考，实物的零位和方向仍以测量确认。

```bash
python3 field/calibration.py fit observations.json --out joint_calib_right_candidate.txt
```

程序输出新的候选文件及 C 点复核误差。候选文件使用单独名称，原文件路径若已存在会拒绝覆盖。用它规划时，需让模型角度、镜头安装外参和场地坐标一致，再按实测范围填写现场配置。
