使用已登记的有限文件输入。旧观察任务停止后，可导入下一份素材；旧文件保留。文件格式、大小与范围以接收端核验为准。

当前为独立封闭窗口接入，窗口之间明确分段，不证明实时或连续24小时采集。手机摄像头/麦克风需要浏览器授权及安全上下文；远程设备还需要已部署的认证网络通道。家庭设备请使用已部署的HTTPS接收入口；观察和语音分别使用当前设备的配对密钥。
